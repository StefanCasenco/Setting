# Setting: script v2

Appointment-setting script, toolkit and practice material for trading and ecom leads.

**Start here → script → current toolkit → conversations → drills**

| Step | File / folder | What it is |
|---|---|---|
| 1 | [`SETTING-SCRIPT.md`](SETTING-SCRIPT.md) | The script. Single source of truth. Fixed spine, freestyle only inside CURRENT |
| 2 | [`drills/READ-ALOUD.md`](drills/READ-ALOUD.md) | Only the fixed SAY lines. Read aloud daily |
| 3 | [`current-situation/`](current-situation/README.md) | Playbook, 170+ questions, ladders by first answer, mistakes and fixes, 30 scenes |
| 4 | [`conversations/`](conversations/README.md) | 28 full example calls, organised by what the prospect gives first |
| 5 | [`drills/`](drills/) | Self-play, review-your-calls, call log + A/B tally, AI prospect simulator |
| - | [`SETTING-SOP.md`](SETTING-SOP.md) | The why and the judgment calls (partly rebuilt, see `PROGRESS.md`) |
| - | [`archive/`](archive/) | Decisions brief; old v1 material belongs here |

Everything is for feel, not a substitute for live calls. All people in examples are invented.

## Check the examples
`python3 tools/lint_conversations.py` (from the repo root) checks structure, banned phrases, stacked questions, turn length and personal data.
