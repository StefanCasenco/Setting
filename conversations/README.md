# Conversations: full setting calls

Read these to feel how a call flows. They are **not** scripts to memorise. The fixed lines live in `../SETTING-SCRIPT.md`; everything inside CURRENT is freestyle.

## How to use
1. Read one call straight through, out loud, setter side.
2. Cover the setter lines and answer the prospect yourself.
3. Read "Worse version" last, and spot your own habits in it.
4. Then talk to real people. Reading is not reps.

Tags: `[FRAME] [INTENT] [EI] [CURRENT L1-L5] [RECAP] [TIMEFRAME] [WGW] [WHY NOW] [FIN] [PITCH] [LOCK] [SHOW UP]`. `[TEST A|B|C]` marks which TIMEFRAME variant was used. All people are invented.
