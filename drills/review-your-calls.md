# Review your calls: the pause-and-ask drill

Do this with a recording of one of your own calls. 20 minutes.

## The drill
1. Play the CURRENT section only.
2. After every prospect sentence, **pause** and ask: "How could I have gotten deeper?"
3. Write one line: the better question you could have asked.
4. Keep going until the section ends.

## Score it
| Check | Count |
|---|---|
| Layers reached (L1-L5) | |
| Echoes used | |
| "What do you mean?" used | |
| Questions that assumed something | |
| Stacked questions | |
| Minutes in CURRENT (target 4-6) | |
| Exit test met? (pain in their words + one feeling + one cost) | yes / no |

## Look for the habits
- Fact questions when they just gave you a feeling
- Challenge questions ("why is that a problem?")
- "Why aren't you / why haven't you" (defensive answers)
- Recapping the tactical goal
- Digging after the exit test

## Weekly
Pick the one habit that shows up most. Write its fix on a card, and read it before each call. Fix one habit at a time.
