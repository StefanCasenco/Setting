# Call log template

Copy one block per call.

```
Date:            Offer: trading | ecom      Source: ad | guide
Name (first):                     Country / time zone:
Length (min):    CURRENT (min):   Layers reached: L_
First-answer type (1-16):
Exit test met?   yes | no
TIMEFRAME variant used:  A | B | C
  Did they answer with:  "I need guidance" | self-blame | other
Outcome:         booked | DQ | no-book
Money:  goal ____ / income ____ / saved per month ____ / saved ____ (for ____)
Flags:  tight money | partner | ghost risk | skepticism
What went well:
What I'd change:
```

## TEST tally (TIMEFRAME line)

Run 20 calls, then keep the winner. Don't change the script during the test.

| Variant | Calls | "Need guidance" | Self-blame | Other |
|---|---|---|---|---|
| A. Why haven't you been able to see success… | | | | |
| B. What do you feel has been missing to get you there? | | | | |
| C. What do you think would make the difference? | | | | |

Winner = most "need guidance" answers with the least self-blame.

## Show-up tracker
Booked · showed · no-show · rescheduled. Note which SHOW UP variant you used.
